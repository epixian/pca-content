# Actor links

Date: 2026-11-20. This report covers the 73 files that were in `content/actors/` at the start.
43 actors got a `links:` mapping. No other field was changed.

Verification method: I read the raw HTML (or a rendered fetch) of the page in the third column.
Each link in the second column appears on that page as an `href`, unless the note says otherwise. "Linked from" means the href is on the home page; I did not check if it is in the header or footer.
I changed `twitter.com/handle` to `https://x.com/handle`. I removed tracking parameters.
